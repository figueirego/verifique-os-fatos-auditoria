## Limites

Esta é uma crítica documentada de escopo definido. Não é perícia de infraestrutura, auditoria eleitoral nem prova de intenção de quem mantém o projeto. Não houve rechecagem independente integral das 75 falas nem contato com o responsável. A ausência de documentação localizada não prova inexistência do processo.
